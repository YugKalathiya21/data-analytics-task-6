# 🏠 Housing Data Transformation & Feature Engineering

## Project Overview

This project focuses on transforming and enhancing housing data for machine learning applications. Various feature engineering techniques were applied to improve data quality and model readiness.

---

## Objectives

- Convert categorical features into numerical format
- Scale numerical variables
- Create interaction terms
- Prepare dataset for predictive modeling

---

## Techniques Applied

### One-Hot Encoding
Converted categorical variables into machine-readable numerical features.

### Feature Scaling
Standardized numerical features using StandardScaler.

### Interaction Terms
Generated new features by combining existing variables.
